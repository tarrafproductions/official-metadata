# Правки каталога от 12 сентября 2026

По указанию Алика Таррафа применены новые обложки для SNG-027, SNG-042, SNG-043, LIVE-I и LIVE-II, а SNG-118 переименован в POLICE. Эти правки сохранены. История исходных подтверждений доступна в [коммите 81d45fc](https://github.com/tarrafproductions/official-metadata/commit/81d45fc816cde3a3ba187e322f0ded3321f59604).

После замечаний Назара устранено дублирование:

- Единственная папка с актуальными изображениями — `assets/covers/by-release/`. Все 278 файлов сохранены побайтово; 287 файлов второй папки удалены из текущей версии. Старые версии остаются в истории Git.
- Номер файла совпадает с ID релиза: SNG-160 → `cover-160.webp` (EISENHERZ); SNG-218 → `cover-218.webp` (Jordan). Прежняя независимая нумерация картинок удалена.
- Названия, UPC, ISRC и кредиты берутся из канонических JSON-LD. Карта обложек, JSON/CSV и таблица дискографии генерируются; вручную они не редактируются.
- В каждой строке JSON/CSV есть `catalog_id` и `cover_path`. Генератор не копирует и не перезаписывает изображения. Проверки блокируют пропущенные и лишние файлы, а также устаревшие результаты генерации.

## Подключение на сайте

1. Обновить привязку репозитория до коммита с этой правкой и заменить старую импортированную папку ресурсов снимком из `assets/covers/by-release/`.
2. Читать `exports/catalog.json`: ключ релиза — `catalog_id`, обложка — `cover_path`. Порядок элементов массива не определяет соответствие.
3. Если интеграция уже использует `release-map.json`, оставить `catalogId`/`releaseId`/UPC и `coverPath`. Убрать обращения к удалённым архивным полям; точные изменения описаны в [контракте интеграции](website-integration.md#release-artwork).
4. Пересобрать сайт и обновить кэш изображений. Публикация репозитория сама по себе не обновляет сайт на Netlify.

Следующие изменения: заменить обложку на месте либо отредактировать канонический JSON-LD, затем выполнить команды из [правил репозитория](../AGENTS.md). Вторую папку, ручной список соответствий и очередной файл исправлений создавать не требуется.
